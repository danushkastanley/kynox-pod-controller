# Contributing

Thank you for helping improve pod-controller.

1. Open an issue for significant behavioural or protocol changes.
2. Create a focused branch and keep the diff small.
3. Add or update tests when behaviour changes.
4. Run `go test ./...` and `go vet ./...`.
5. Update documentation for configuration or protocol changes.
6. Open a pull request describing the change, risk, and verification.

Do not commit credentials, certificates, `.env` files, cluster data, generated
binaries, or personal information. New dependencies need a clear maintenance and
security justification.

By participating, you agree to follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
